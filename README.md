# haplotype_stucture_data_code

&emsp;&emsp;This directory contains scripts to reproduce the analyses and figures from the study.

## 01generate_founder_population
&emsp;&emsp;code to sample and generate the founder population for simulations



## 02slim_simulationA_LD_sampling
&emsp;&emsp;founder population were generated by random sampling
```
  parameters:
    Sample size: 400 (number of founder haplotypes)
    Census population size: 1250
    Number of selection targets (6): 10, 100, 1000, 5000, 10000, 20000(random Sampled from segregating site)
    Selection strength (3): 10, 50, 100(sum of the selection coefficients)
    Two extra simulations under neutrality with popsize of 1250 and 300 (2)
    Linkage: LD (recombination map from Comeron et al. 2012)
    Runs (10): 10
    Supergroup (3): Supergroup I, II and III
    Replicates within each replicates (5): 5
    Number of simulations: $(6*3+2)*10*3*5 = 3000$
```
